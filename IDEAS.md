# Домашний дашборд — идеи (на потом)

Архитектура: веб-страница (Vercel) + Supabase, в лаунчере показывается через WebView.

| Виджет | Источник данных |
|---|---|
| Меню со всеми виджетами (вкл/выкл, порядок) | своё |
| Время и дата | есть |
| Погода + температура воды | Open-Meteo (+ Marine API) |
| Адженда всей семьи, включая расписание Алисы | Google Calendar / iCloud (iCal или API) |
| График цены электричества | Red Eléctrica PVPC API |
| Список покупок | Supabase |
| Меню на сегодня | Supabase |
| Мотивационная цитата (3 языка) | свой список / Claude |
| Spotify | Spotify Web API |
| YouTube | YouTube Data API |
| Гонка хороших и плохих привычек | Supabase |
| Фото дня | Google Photos / папка |
| Список дел | Supabase / Google Tasks |
| Поливка растений | перенести данные в Supabase |

Порядок: 1) время, погода, электричество, цитата → 2) списки + растения → 3) привычки → 4) Spotify, YouTube, календари с логином.
